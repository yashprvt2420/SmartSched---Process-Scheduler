Scheduling Algorithms

Formal definitions, working mechanisms, and fundamental DSA structures powering SMARTSCHED.

▶ Open Simulator
01 • FIFO QUEUE

FCFS

First-Come, First-Served

Processes execute strictly in the order of their arrival in the ready queue. Simple and deterministic.

DATA STRUCTURE Linear FIFO Queue (std::queue / Ring Buffer) HOW IT WORKS
  1. Incoming processes enqueue at the tail.
  2. CPU picks the head element of the queue.
  3. Selected process executes to completion (non-preemptive).
  4. The next process in FIFO order is dispatched.
⚡ Tradeoff: Minimal algorithmic overhead, but prone to convoy effect where large bursts stall short jobs.
02 • SHORTEST JOB FIRST

SJF

Shortest Job First

Selects the currently available ready process that has the lowest remaining CPU burst time.

SELECTION RULE Minimum Burst Time Comparator (Min-Heap) HOW IT WORKS
  1. Examine all arrived processes in ready queue.
  2. Filter candidate with minimum CPU burst requirement.
  3. Execute the selected process completely.
  4. Repeat for remaining arrived workloads.
⚡ Tradeoff: Mathematically proven optimal average waiting time, but susceptible to starvation of long bursts.
03 • CIRCULAR QUEUE

Round Robin

Preemptive Time-Quantum Slicing

Every process is allocated an equal slice of CPU execution time (quantum) in a cyclical ring queue.

DATA STRUCTURE Circular Queue (Array Ring Buffer)
P1 → P2 → P3 → P4 ↻ [Quantum = 2ms]
KEY PRINCIPLE

If a process doesn't finish within its quantum slice, it is preempted and pushed to the back of the queue.

⚡ Tradeoff: Maximum responsiveness and fairness for timesharing systems; sensitive to quantum size tuning.
04 • PRIORITY HEAP

Priority

Rank-Driven Scheduling

CPU cycles are awarded to the available process holding the highest priority rank (numerically lowest rank in this lab).

DATA STRUCTURE Priority Queue (Binary Min-Heap)
P2 — Priority 1 (Highest Rank)
P3 — Priority 2
P1 — Priority 3
P4 — Priority 4 (Lowest Rank)
KEY PRINCIPLE

Simulates real-world operating systems where kernel tasks take precedence over background user processes.
