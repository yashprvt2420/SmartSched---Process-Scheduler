CPU scheduling, visualized and benchmarked.

SMARTSCHED bridges Operating Systems theoretical principles with Data Structures implementations. It benchmarks standard scheduling algorithms against custom user workloads and automatically highlights the scheduler with lowest average waiting time.

PROBLEM STATEMENT

Why CPU scheduling matters

Because single CPU cores execute instructions sequentially, operating systems rely on schedulers to determine which process gains control next. Depending on process burst distributions, an algorithm can either trigger catastrophic convoys or achieve near-zero queuing delays.

DECISION CRITERIA

Recommendation algorithm

  1. Collect waiting times across all active simulation algorithms.
  2. Compute average waiting time (\(AWT = \frac{1}{N} \sum W_i\)).
  3. Identify minimum AWT candidate.
  4. Highlight candidate with the optimal badge and render execution timeline.
