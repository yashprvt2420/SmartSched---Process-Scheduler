# SMARTSCHED

SMARTSCHED is a CPU scheduling simulation project that demonstrates
Operating Systems and Data Structures concepts through interactive
simulation and algorithm comparison.

## 🚀 Live Demo

🔗 **[View SMARTSCHED Live](https://smartsched-ten.vercel.app/)**

## 📌 Features

- FCFS Scheduling
- SJF Scheduling
- Round Robin Scheduling
- Priority Scheduling
- Average Waiting Time comparison
- Automatic selection of the best scheduling algorithm
- Interactive Gantt chart
- Process-based simulation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- C
- Data Structures
- Operating Systems concepts
